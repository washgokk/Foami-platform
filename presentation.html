Revenue 3 ทาง — Hybrid Marketplace

1. Own-store Revenue

บริการของร้าน Foami Official เอง

  • ล้างรถ Package 129-189 บาท/คัน
  • ต่อ พ.ร.บ. +50-100 บาท (Manual)
  • Add-on เติมลม น้ำมัน เปลี่ยนน้ำมัน
  • รายได้ 100% ไม่หักส่วนแบ่ง

2. GP Commission

ร้านพาร์ทเนอร์รับงานผ่าน Platform

  • หัก GP 15-20% ต่อ Order อัตโนมัติ
  • Stripe Connect จัดการ Split เงิน
  • 80% เข้า Shop Wallet ร้านนั้น
  • ร้านขอ Withdraw ผ่าน Admin

3. SaaS Subscription

ระบบจัดการขั้นสูงสำหรับร้าน

  • Starter: ฟรี (Booking พื้นฐาน)
  • Growth 299฿/เดือน: CRM + Push
  • Pro 790฿/เดือน: RFM + Audit
  • Enterprise 1,290฿/เดือน: API
Bootstrap ด้วยทุนเริ่มต้น 10,000 บาท → Revenue-funded Growth → ไม่กู้ ไม่มีหนี้ → กำไรตั้งแต่ปีแรก
กระบวนการ — ร้านพาร์ทเนอร์

Partner Onboarding Flow 3 ขั้นตอน

Step 1 — Admin ออก Invitation

  • เราติดต่อร้านล้างรถที่สนใจ
  • Admin สร้าง Code ใน Dashboard
  • ส่ง Code ให้ร้านทาง LINE / อีเมล
  • Code หมดอายุใน 7 วัน

Step 2 — ร้าน Setup ตัวเอง

  • ใส่ Code → สมัคร Email + Password
  • กรอกข้อมูลร้าน ชื่อ ที่อยู่ โลโก้
  • วาด Zone บนแผนที่
  • เพิ่ม Services + ตั้งราคา S/M/L
  • เพิ่ม Staff + ตั้ง Schedule

Step 3 — ร้านพร้อม Live

  • ร้านมี URL ของตนเอง
  • ลูกค้าจองผ่าน Foami ได้เลย
  • Stripe Connect เชื่อม (รับเงินได้)
  • ขึ้น Marketplace ถ้า Plan = Growth+

รับต่อ พ.ร.บ. รถจักรยานยนต์ ถึงที่

ทำไมบริการนี้จำเป็น?

  • นักศึกษาไม่รู้ต่อ พ.ร.บ. ที่ไหน
  • ไม่มีเวลาออกไปต่อเอง
  • เดินทางไปสำนักงานไม่สะดวก
  • ลืมต่อ ขาดการคุ้มครอง

Value ที่ลูกค้าได้รับ

  • จองล้างรถ + ต่อ พ.ร.บ. ในทริปเดียว
  • ไม่ต้องออกจากหอพัก
  • ได้กรมธรรม์ใหม่พร้อมรถสะอาด
  • ค่าบริการแค่ ~50-100 บาท
