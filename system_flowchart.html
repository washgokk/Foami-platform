⚙️ Platform Admin — Daily Workflow
🔑
Login Platform Admin
เข้า platform.foami-wash.vercel.app ด้วย Email + Password ที่ Foami กำหนด
POST /api/auth/platform-login
📊
ดู Platform Dashboard
ดูรายรับรวมทุกร้าน, จำนวน shops, bookings วันนี้, withdrawal requests ที่รอ
GET /api/platform/stats
✉️
สร้างรหัสเชิญร้านใหม่
ใส่ Email ร้าน, เลือก Plan → Generate Code → ส่ง Email อัตโนมัติผ่าน Resend
POST /api/platform/invitations
Code: FOAMI-XXXXX Expires: 7 วัน
💸
อนุมัติการถอนเงิน
ดูรายการถอนที่รอ → ตรวจสอบ → โอน PromptPay จริง → Upload Slip → Mark Complete
PUT /api/platform/withdrawals/[id]/complete
⚙️
ปรับ Commission Rate
ปรับ % commission รายร้าน (default 20%) ได้ตามข้อตกลงพิเศษ
PUT /api/platform/shops/[id]/commission
🏪 Shop Owner — Onboarding
📧
ได้รับ Email เชิญ
คลิก Link ใน Email → เข้าหน้า Register พร้อม Code สำเร็จ
📝
ลงทะเบียน Shop
กรอกชื่อร้าน, ที่อยู่, โลโก้, เบอร์ติดต่อ, และสร้าง Email+Password
POST /api/platform/shops/register
🧙
Onboarding Wizard (5 ขั้น)
ตั้งค่า Services → สร้าง Branches → วาด Zones (polygon) → เพิ่ม Staff → ตั้ง Schedule
ขั้น 1: Services ขั้น 2: Branches ขั้น 3: Zones ขั้น 4: Staff ขั้น 5: Schedule
🗺️
ร้านขึ้น Marketplace
ร้านจะปรากฏบนแผนที่ Marketplace ทันที (ถ้าเปิด is_marketplace_listed)

🧑‍🔧 Staff — Job Workflow
🔑
Login Staff Portal
Email + Password → ระบบ auto-detect shop จาก staff table
📱
รับ Push/LINE Notification
มีงานใหม่เข้า → Staff ได้รับแจ้งเตือนบน LINE และ Web Push
✅
รับงาน
กด "รับงาน" → Status เปลี่ยนเป็น confirmed → ลูกค้าได้รับแจ้ง
PUT /api/bookings/[id]/accept
🏍️
ออกรับรถ
กด "ออกรับรถ" → Status: picking_up → ถ่ายรูปรถก่อนล้าง (Before Photo)
POST /api/photos { type: 'before' }
🫧
เริ่มล้างรถ
Status: washing → Chat กับลูกค้าได้ → ถ่ายรูปหลังล้าง (After Photo)
POST /api/photos { type: 'after' }
🚗
ส่งรถ + แจ้งยอดเพิ่ม (ถ้ามี)
Status: delivering → ถ้ามีค่าบริการเพิ่ม → แจ้ง Admin → รอลูกค้าจ่าย
🎉
งานเสร็จ
Status: completed → ลูกค้า rate + review → Platform settle เงิน 80% เข้า Wallet ร้าน
👤 Customer — จองบริการ
🗺️
เข้า Marketplace หรือ Link ร้านโดยตรง
ค้นหาร้านบนแผนที่ → เลือกร้าน → หรือเข้า shop.foami.app/[shopId] โดยตรง
ผ่าน Marketplace ผ่าน LINE QR ผ่าน Link โดยตรง
🔑
Login / Register
สร้าง account ด้วย Email+Password หรือ LINE OAuth (ถ้าร้านรองรับ LIFF)
POST /api/auth/register | /api/auth/login
📦
Step 1: เลือก Package + Addon
เลือกบริการ (ล้างสี, ล้าง+เคลือบ, บำรุงรักษา) + เสริม (เติมลม, น้ำมัน, เปลี่ยนน้ำมัน)
GET /api/shops/[id]/services
📍
Step 2: Pin ตำแหน่งรับ-ส่ง
ใช้ MapPicker → ระบบตรวจ Zone → คำนวณ Extra Fee ถ้าอยู่นอก Zone
ใน Zone → ฟรี นอก Zone → +ค่าเดินทาง
🕐
Step 3: เลือกวันและเวลา
ดู Time Slots ที่มีพนักงานว่าง → เลือกวัน+เวลา (ต้องล่วงหน้า 20 นาที)
GET /api/shops/[id]/availability
📋
Step 4: สรุปและใส่ Discount
ดูสรุปราคา → ใส่ Discount Code (ถ้ามี) → ยืนยันรายการ
POST /api/discount/validate
💳
Step 5: ชำระเงิน
เลือก Stripe (บัตร/PromptPay) หรือ โอนเงิน+แนบสลิป
Stripe → Auto confirm โอน → Admin ตรวจสอบ
🎉
ติดตาม + รับรถ + รีวิว
ดู Real-time Status → Chat กับ Staff → รับรถ → ให้คะแนน (1-5 ดาว)
POST /api/bookings/[id]/review
